# 公园喷泉启停与水质维护平台

管理喷泉区域、水池、循环泵、喷头组、运行时段，以及水位/浊度/余氯监测、补水、药剂投放、
清池任务、故障停运与复开检查。设备与读数均为**演示数据**（模拟适配器）。

## 启动

零第三方依赖，Python 3.11 标准库即可：

```bash
python3 -m app.demo   # 一条命令生成样例：水质超限拦截 / 天气停运 / 复开退回
python3 run.py        # 启动平台  →  http://127.0.0.1:8000
```

可选：`python3 run.py --port 8013 --no-scheduler`

## 核心规则

- **到点先校验**：计划到点启动前校验水位、浊度/余氯、泵状态/温度、喷头压力、天气、封控区
  闯入与药剂观察期；任一不满足即拦截并写明原因。
- **计划互斥**：同一水池运行时段不可重叠；清池锁定整个水池并暂停计划，二者不能同时进行。
- **观察期**：投药后进入 30 分钟观察期（超量翻倍），期间禁止启动；正在运行则立即停运。
- **故障处置**：水位不足/水质超限/喷头堵塞/泵体过热自动保护停运并建工单；天气预警停运、
  解除自动闭环；非计划时段人工启动记为误启动；封控区闯入紧急停运。
- **复开检查**：维修或清池结束后，必须完成**水质复测 + 喷头试运行**才能复开；复测合格
  养护员可批，指标越限仅**主管**可批准；材料不全或退回后须补齐重新申请。
- **启动幂等**：两人并发启动同一水池，仅一次真正生效，另一次合并返回。

## 视图

区域总览（池体轮廓 + 喷头组短线，水质数值标在池体旁）、运行日历（安静时间带 + 停运原因
文本）、水质记录（仅保留必要阈值线的趋势图）、泵组状态、药剂台账、清池流程、故障维修、
复开审批。

## 存储与调度

- SQLite（`data/fountain.db`）保存计划、读数、工单、审批与日志；现场附件存
  `data/attachments/`（读数录入与清池任务支持 multipart 上传）。
- 进程内调度线程负责到点启停、每分钟采样、设备保护、天气联动与复测/观察期提醒。
- `app/adapters.py` 返回模拟水位、水质、泵温、喷头压力与天气，可在页面或 API 注入异常工况。

## 测试

```bash
python3 -m unittest tests.test_platform -v
```

覆盖：计划互斥、清池与运行互斥、启动条件校验（水位/水质/天气/闯入/堵塞/过热/误启动）、
观察期与超量阻断、并发启动幂等、复开审批权限与退回流程。
