# 公园喷泉启停与水质维护平台

管理喷泉区域、水池、循环泵、喷头组、运行时段与水位 / 浊度 / 余氯读数，
覆盖补水、药剂投放、清池、故障维修、复开审批的完整闭环。设备与读数均来自
**模拟适配器**（演示数据），无外部依赖，仅使用 Python 标准库与 SQLite。

## 本地启动

```bash
# 1) 初始化演示数据库（首次可省略，serve 会自动建库）
python3 -m fountain.cli reset

# 2) 一条命令生成三类样例：水质超限拦截 / 雷暴天气停运 / 复开退回
python3 -m fountain.cli demo-sample

# 3) 启动平台（进程内调度器 + Web 界面）
python3 -m fountain.cli serve            # http://127.0.0.1:8000
# 可选：--browser 自动打开浏览器；--port 改端口；--tick 改调度间隔（默认 10s）
```

测试：

```bash
python3 -m unittest discover -s tests -v
```

## 核心运行规则

1. **到点先校验后启动**：调度器在计划开始时间逐项检查
   水位（0.80–1.60 m）、浊度（≤5.0 NTU）、余氯（0.3–1.0 mg/L）、
   循环泵（无故障、温度 <75 ℃）、喷头组（无堵塞）、天气与水池锁定状态，
   全部满足才启动；任一不满足则记为 `blocked` 并生成对应处置事件。
2. **药剂观察期**：投药后进入 30 分钟观察期，期内计划阻断；观察期结束、
   条件恢复后调度器自动重试。单次投加 >12 L 判为**药剂超量**，立即停喷，
   复测达标前禁止启动。
3. **清池互斥与锁定**：清池锁定整个水池并暂停计划，运行中不能清池、
   清池中不能启动；同一水池不允许重复清池。
4. **维修/清池复开**：作业结束后必须完成**水质复测 + 喷头试运行**，
   养护员发起复开，**主管**批准；缺项或越限时主管退回，退回原因留痕。
5. **启动幂等**：`run_sessions (schedule_id, run_date)` 唯一约束 +
   `BEGIN IMMEDIATE` 事务，两人/多线程并发启动只产生一个运行实例，
   重复启动返回 `idempotent`。
6. **异常处置**：
   - 水位不足 → 阻断启动并提示补水（补水登记后复测）；
   - 水质超限 → 阻断，人工/复测达标后恢复；
   - 喷头堵塞 / 泵体过热 → 故障停运锁定，走维修复开流程；
   - 暴雨/雷暴/台风或 ≥6 级风 → 天气停运，天气恢复后自动重试；
   - 人工误启动（条件不满足）→ 拦截并记录“误启动”事件；
   - 游客进入封控区 → 紧急停喷，养护员现场处置解除后方可恢复。
7. **角色**：养护员（keeper）处理现场任务；主管（supervisor）独占
   越限复开审批，页面右上角可切换身份。

## 架构

```
fountain/
├── config.py       # 阈值、路径、角色
├── db.py           # SQLite schema / 连接 / IMMEDIATE 事务
├── adapters.py     # 模拟适配器：水位、水质、泵温、喷头、天气（可注入场景）
├── services.py     # 领域服务：校验、启停、互斥、观察期、清池、维修、复开、事件
├── scheduler.py    # 进程内守护线程：到点启停 / 天气停运 / 复测提醒
├── seed.py         # 演示数据
├── cli.py          # init / reset / demo-sample / serve / tick
└── web/            # stdlib http.server + 原生 JS 前端（server.py/index.html/app.js）
data/
├── fountain.db     # SQLite：计划、采样、台账、任务、审批、事件
└── attachments/    # 现场附件（清池/故障照片等，本地目录保存）
```

- **存储**：运行计划、采样、药剂台账、清池/故障/审批全部落 SQLite；
  现场附件保存在 `data/attachments/`，数据库只存元数据。
- **调度**：`serve` 启动守护线程，默认每 10 秒 tick 一次，负责定时启停、
  天气突变停运、观察期/天气恢复后的自动重试与复测提醒。
- **演示适配器**：`adapters.set_scenario(pool_id, turbidity=…)` /
  `set_weather(...)` 可注入任意场景，界面“演示适配器注入”卡片也可操作。

## 测试覆盖

`tests/test_platform.py`（25 项）：条件校验各分支、清池/计划互斥、
观察期阻断与到期解除、超量处置、启动幂等（含 8 线程并发仅一实例）、
复开审批权限（养护员越权、主管退回、复测试运行后批准）、误启动、
游客封控与天气停运/恢复重试。
